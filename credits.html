HospitalBench

Frontier models start hospital chores well, then lose the thread.

HospitalBench puts a mobile robot arm in simulated hospital rooms and asks a model to finish real chores, where each step sets up the next. We are asking AI labs for compute and API credits to run it on every frontier model. We are not asking for money.

What the benchmark is

10hospital chores, from answering a phone to filing a patient's chart
5+chained sub-tasks per chore; each leaves the room the way the next one needs it
2start states per chore, so a memorised path does not carry over

Every chore is built in NVIDIA Isaac Sim with physics, cameras and people walking through the room. A scripted robot completes every chain, so each chore can be done. Before a chained run counts, each model must also pass every sub-task on its own. A failure inside the chain then points at the long-horizon part, not at a step the model cannot do.

What credits would pay for

CreditWhat it runs
GPU (NVIDIA)Isaac Sim with cameras and moving people. One 96 GB RTX PRO 6000 Blackwell runs about 8 jobs at once; every model run, scripted check and chained walk needs one of those slots for 20 minutes to several hours.
Claude API (Anthropic)Claude runs take the most calls: one Opus 5.5 sub-task costs about $0.10 to $10 in API use, and a chained walk strings five of them together.
OpenAI APIGPT Terra and Sol runs on every chore, both start states, three walks each.
Gemini API (Google)Gemini Argon runs, so the comparison covers every major frontier family.

What your lab gets

  • Your models evaluated on all ten chores, both start states, with the same prompts, pictures and tools as every other model.
  • A per-run breakdown of where each chain breaks: which sub-task, and what the robot did there.
  • Results shared with your team before the public release.
  • Credit for your support in the release.
